数値範囲 画像プレビュー

画像URLテンプレートと数値の範囲を指定すると、存在する画像だけを順次チェックしてプレビュー一覧に表示します。 URLには {number} を含めてください。

数値は先頭ゼロ付き（例: 000001）でも入力できます。開始・終了の桁数のうち長い方でゼロ埋めします。
存在確認は HEAD/GET（no-referrer）を試行します。CORS 制限がある場合は GET（no-referrer）に自動切り替えします。
同時チェック数 N・リクエスト間隔 T 秒の場合、約 N 件/T 秒で並列チェックします（例: 10・1秒 → 1秒あたり10件）。
チェック済み: 0 / 0
見つかった画像: 0 件
URLと数値範囲を入力して「チェック開始」を押してください。
