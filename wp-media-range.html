WordPress メディアID範囲プレビュー

ドメインと開始ID・件数でメディアを順次確認するか、キーワードで WordPress メディアを検索できます。存在する画像・動画・音声の source_url をサムネイル一覧に表示します。

キーワード検索は /wp-json/wp/v2/media?search= を使います。件数は取得の上限です。同じキーワードはキャッシュから表示します。
開始IDから指定件数分の連番IDを、/wp-json/wp/v2/media/{ID} で確認します。404（投稿などメディア以外のID）はスキップします。
一覧のプレビューは画像なら medium / thumbnail、なければ source_url を使います。リンク先は常に source_url です。
取得結果はローカルストレージに保存します。同じサイト・IDは次回以降 API を呼ばずキャッシュから表示します。
検索条件と一致したメディア一覧は、この端末の IndexedDB（利用できない場合はローカルストレージ）に検索履歴として保存します。
同時チェック数 N・リクエスト間隔 T 秒の場合、約 N 件/T 秒で並列チェックします。キャッシュ済みのIDは待機しません。CORS 制限があるサイトでは取得できません。
